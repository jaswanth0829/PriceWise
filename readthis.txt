PRICEWISE – PRODUCT PRICE TRACKER & ANALYZER

PROJECT DESCRIPTION--

PriceWise is a full-stack web application that helps users track product prices from e-commerce websites
and receive alerts when prices drop below a target value.The platform stores historical price data,
visualizes trends using interactive charts, and automatically updates prices using scheduled scraping.

FEATURES--

• User Registration & Login Authentication
• Product Price Tracking
• Historical Price Storage
• Interactive Dashboard with Charts
• Email Price Drop Alerts
• Automated Price Updates
• Responsive Frontend Design
• REST API Support
• Dark Mode UI
• Multi-user Support

HOW TO RUN PROJECT--

1. Install dependencies:
pip install -r requirements.txt

2. Create database:
python create_db.py

3. Run Flask application:
python app.py

4. Run background updater:
python services/updater.py

RESUME DESCRIPTION--
PriceWise – Product Price Tracker & Analyzer
A full-stack web application to monitor product prices over time, visualize trends, and alert users on price drops.
• Built a full-stack price tracking platform using Python, Flask and SQLite to store and query historical product price data.
• Designed interactive dashboards using Chart.js to visualize price history, averages, and trend graphs.
• Implemented an automated price-fetching mechanism with scheduled scraping to keep product data up to date.
• Developed a price drop alert system that notifies users when a tracked product falls below their target price.
• Built a responsive frontend with HTML, CSS and JavaScript; backend follows RESTful API principles using Flask.
